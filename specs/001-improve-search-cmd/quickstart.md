# Quickstart: Enhanced Repo Search Keybindings in search_cmd

## Step-by-Step CLI Usage

1. Run the repo search command:
   ```
   search_cmd "my-repo"
   ```
2. Use keybindings to take action on any result:
   - Press `alt-c` to clone a selected repository
   - Press `alt-f` to fork a selected repository
   - Press `ctrl-o` to open the repository in your browser
   - Press `ctrl-y` to copy the repository URL
   - Use `alt-1`, `alt-2`, `alt-3` to filter results
   - Use `alt-n`, `alt-d` to sort results
3. Observe real-time updates and feedback for each action
4. If an action fails, review the error message in the interface

---

This quickstart validates the end-to-end user flow for the enhanced repo search keybindings feature.
